TOMI PORTFOLIO — STARTER PROJECT

FOLDER STRUCTURE
- index.html                 Homepage
- about.html                 About / CV
- testimonials.html          Client testimonials
- style.css                  Shared styling
- script.js                  Shared navigation, contact, and lightbox logic
- work/long-forms.html       Long-form video projects (10 slots)
- work/short-forms.html      Short-form video projects (10 slots)
- work/thumbnails.html       Thumbnail gallery (10 slots)
- assets/images/             Store general images here
- assets/thumbnails/         Store thumbnail designs here
- assets/icons/              Store icons/logos here

BEFORE PUBLISHING
1. Open script.js.
2. Replace WHATSAPP_NUMBER = "234XXXXXXXXXX" with your real WhatsApp number in international format, digits only. Example: 2348012345678.
3. Add your X profile URL to X_PROFILE_URL.
4. Replace placeholder project titles/descriptions and add video IDs / image paths.
5. Add real client testimonials only after getting permission to publish them.
6. Add your own project cover images and logo as needed.

VIDEO PLACEHOLDERS
On work/long-forms.html and work/short-forms.html, each project has a button with data-video="".
Set it to the YouTube video ID only, for example data-video="pA1a5Xu1928".
This starter includes a shared modal playback system, but playback should be tested with your actual videos before publishing.

THUMBNAIL PLACEHOLDERS
On work/thumbnails.html, each project has data-image="".
Set it to a relative image path such as ../assets/thumbnails/project-01.jpg.
Use optimized JPG or WebP images and keep all designs in a consistent aspect ratio (usually 16:9).

The site uses Google Fonts via an online stylesheet, so the fonts require an internet connection.
This is a static HTML/CSS/JS site and does not yet include a content management dashboard.

Music Videos / Teasers portfolio page: work/music-videos.html (10 project slots).
